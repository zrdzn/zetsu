# Zetsu
Zetsu is an engine modification for **Project Zomboid dedicated servers**, designed to improve server performance and expand modding capabilities.
It introduces a native Java plugin system, allowing developers to build and run server plugins directly in Java. Alongside plugin support, Zetsu adds engine optimizations, async processing, and configurable performance tweaks.
